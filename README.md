# PSIB2026Q2-TPI-Grupo11-Vleugels_Moro_Pezzano

## Estructura

- `src/`: código fuente.
- `scripts/`: scripts de ejecución y utilidades.
- `data/`: datos locales, excluidos de Git.
- `results/`: resultados generados.

## Entorno de trabajo

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Dependencias: NumPy, NiBabel, SciPy, scikit-image, Matplotlib y OpenCV.
